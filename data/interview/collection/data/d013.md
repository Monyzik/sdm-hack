# Заявка ING-203 на расшифровку сканов

Синтетическая заявка от 2026-06-15; ответственная Елена Морозова. Для ING-203 предложен кабинетный разбор вымышленного приложения «Записка о комплекте». Оно изображает три сканированные страницы с условными печатными строками; реальный документ или изображение не передаются.

На первой странице задан заголовок, на второй таблица из шести строк, на третьей пояснение к таблице. Елена предлагает оформлять расшифровку отдельно по страницам, чтобы цитата из пояснения не выглядела частью строки таблицы. Номер страницы должен сопровождать каждую спорную запись.

Запрос ING-213 касается поворота обложки и не разрешает менять распознанные числа. Для смысловой проверки таблицы предложен Денис Лебедев. Окончательное использование расшифровки потребует человеческого решения; заявка не доказывает наличия OCR в коде демо.
