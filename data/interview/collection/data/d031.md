# Запрос ING-206 о совпадающих именах

Синтетический запрос от 2026-06-15; ответственный Игорь Смирнов. Для ING-206 придуманы два вложения с одинаковым именем «приложение.pdf». Первое пришло в учебном пакете «Север», второе в пакете «Юг». Пакеты не обозначают реальные организации или каналы передачи.

В северном макете две страницы, в южном четыре. Игорь предлагает сохранять имя пакета вместе с именем вложения, поскольку один basename не позволяет выбрать нужный источник. Совпадение имени не доказывает равенство содержимого и не разрешает удалить один из двух экземпляров.

Заявка ING-216 касается только показа длинных имен на экране. В рамках ING-206 предлагается дополнить будущую карточку происхождением и количеством страниц. Сравнение контрольных сумм оставлено следующему кабинетному шагу; результаты вычисления реальных хешей в этой заявке отсутствуют.
