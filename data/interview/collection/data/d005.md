# Лист сверки пустых строк «Архива»

Синтетический лист сверки от 2026-06-18; ответственная Елена Морозова. Кабинетная проверка единственной вкладки «Архива» завершает разбор трех названий из ING-201. Рассматривается нарисованный диапазон из десяти строк после заголовка, без реального чтения электронной книги.

Семь строк содержат карточки, две полностью пусты, еще одна содержит только примечание «перенесено». Предложено считать содержательными карточками семь строк. Строку с примечанием следует сохранить как контекст переноса, но не приписывать ей номер карточки, которого в примере нет.

Игорь Смирнов должен отдельно согласовать правило для пустого значения внутри заполненной строки. Оно не равнозначно полностью пустой строке: отсутствие даты не дает основания удалять карточку. Этот вопрос оставлен открытым для следующего уточнения описи, без изменения уже выполненной задачи T703.
