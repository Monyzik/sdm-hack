# QLT-405: тестовая карточка вложенной заметки

Синтетический документ P007 · 19.06.2026 · Владелец: Денис Лебедев.

Тестовая карточка QLT-405/19-Б выделяет message.note как вложенное поле исключения M-018. Проверка верхнего поля note без пути message.note не считается достаточным доказательством для M-018.

Денис предлагает сохранять полный путь при ручном описании замечаний, поскольку одинаковое конечное имя может встречаться в разных местах макета. Карточка не содержит нового запуска проверки и не закрывает исключение. В качестве будущего доказательства нужны конкретная синтетическая строка и результат просмотра вложенного поля после обработки. Само наличие карточки подтверждает только подготовку сценария проверки. До отдельного подтверждения M-018 остаётся открытым наряду с M-017; число обработанных строк исходного учебного стенда по-прежнему составляет 16 из 18.
