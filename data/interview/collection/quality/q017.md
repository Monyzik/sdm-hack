# QLT-403: записка о соседних кодах ошибок

Синтетический документ P007 · 19.06.2026 · Владелец: Павел Орлов.

Записка QLT-403/19 относит RAG-017 к отставанию индекса от manifest, а RAG-071 — к сценарию закрытого источника для тестовой учётной записи. Перестановка цифр в коде меняет тему разбора и не считается вариантом написания одного события.

Павел предложил проверяющему сначала сверять полный код, затем читать описание, чтобы похожие номера не объединялись по памяти. Это сопоставление уже заданных учебных обозначений, а не отчёт о двух произошедших сбоях. Для первого кода обсуждаются свежесть и управляемое обновление, для второго — проект проверки доступа. Наличие описания второго кода не доказывает реализованный контроль прав. При ответе на неясно названный номер сотрудник должен запросить уточнение, если по вопросу нельзя уверенно выбрать один из сценариев.
