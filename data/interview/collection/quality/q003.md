# QLT-401: карточка составного вопроса о расходах

Синтетический документ P007 · 18.06.2026 · Владелец: Денис Лебедев.

Карточка QLT-401/18-Ф делит вопрос «сколько потратили и кто разрешил резерв?» на два независимых тезиса. Для первого тезиса зафиксировано 800 тысяч рублей затрат; для второго указано, что резерв 600 тысяч рублей не утверждён.

Денис предлагает оценивать полноту по обеим частям, даже если одна часть требует отрицательного ответа. Упоминание запрошенной суммы без статуса согласования будет оставлять вторую часть неразобранной. Карточка используется как бумажный образец для разметки и не содержит ответа модели. Плановый бюджет проекта составляет 2,4 миллиона рублей; эти деньги нельзя складывать с запросом резерва при пересказе уже понесённых затрат. Ответ перед использованием должен утвердить сотрудник.
