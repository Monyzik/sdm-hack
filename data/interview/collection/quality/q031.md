# QLT-406: форма регистрации ошибки разметки

Синтетический документ P007 · 15.06.2026 · Владелец: Денис Лебедев.

Форма QLT-406/15 содержит поля «вопрос», «ожидаемый тезис», «цитата», «вид ошибки» и «ответственный за разбор». Пустая строка формы не считается наблюдением ошибки модели.

Денис подготовил заготовку для будущей ручной оценки синтетических примеров. Вид ошибки нужен, чтобы отделять недостаточное доказательство от неверного числа или пропущенной части вопроса. В форме предусмотрено описание причины возврата карточки, позволяющее другому сотруднику повторить рассуждение. На дату записки заполненного отчёта о качестве нет. Количество заготовленных строк нельзя использовать как число проверенных ответов, а перечень возможных ошибок не является реестром реальных сбоев. Форма предназначена для подготовки оценки, которая ещё должна быть проведена.
